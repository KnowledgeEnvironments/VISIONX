# Changelog

Notable user-facing changes in published source snapshots are documented here. Version labels do not imply maintenance, compatibility, updates, or future releases.

## 1.0.0 — 2026-10-31

- Established the rootless 2D X11 server baseline for visionOS.
- Added MIT-MAGIC-COOKIE-1 authorization and explicit unsafe testing mode.
- Added spatial window lifecycle, input, focus, close, damage, and resize integration.
- Added bundled X.Org bitmap fonts and importable font packs.
- Added exact-pixel and CRT-inspired presentation options.
- Added the gated experimental VisionGL indirect-rendering path.
- Published reproducible build documentation, third-party notices, and a PII-clean public source snapshot.
